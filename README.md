# About project
I implemented web page using css Grid layout.
1 page is home page
2nd page is cards related to 3 different images
3rd page is related to Grid layout it has sidebar, main and footer
4th page is gallery there are 9 images of different things such as nature and sea.
5th page is my portfolio, information about me and my achievements.

You can navigate through the web page with side bar.

# Features
- Flexbox navigation bar
- Flexbox cards with hover effects
- Grid layout with header, sidebar, main content and footer
- 3x3 image gallery with hover captions
- Portfolio combining CSS Grid and Flexbox
- Navigation between all task pages

Open index.html
